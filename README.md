Technologies: PostgreSQL · Supabase · Python · Chart.js · HTML/CSS/JavaScript

Project Overview

A data-driven analytics system for university course timetabling and resource allocation. This project analyzes the complete semester 251 timetable across four faculties (Kỹ Thuật, QTKD, CNTT, Điều Dưỡng) to optimize instructor workload distribution and classroom utilization.

The system includes:

PostgreSQL database with a 14-table star schema (8 dimensions, 3 bridges, 3 facts)
Python ETL pipeline for data profiling and loading (extract_tkb_full.py)
Live dashboard built on Supabase + Chart.js for real-time scheduling insights
Academic deliverables including schema documentation, analytics report, and presentation
